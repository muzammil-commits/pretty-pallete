## ✨ Features & Architecture

### 1. Brand Identity & Visual Aesthetics
- **Seamless Official Logo**: Transparent PNG logo integration without white patchwork boxes across headers, footers, mobile drawers, invoices, and modals.
- **Hero Banner Background**: Integrated panoramic beauty photography with drifting rose petal animations, ambient glow, and mobile-optimized responsiveness.
- **Brand Palette**:
  - Primary blush pink: `#F8C6CF`
  - Soft pastel pink: `#FCE5E8`
  - Rose pink: `#E98B9B`
  - Deep rose: `#A82F4D`
  - Sage green: `#78844B`
  - Dark olive: `#4C542C`
  - Dark brown: `#40251D`
  - Cream & Ivory: `#FFF9EF` & `#F7F3E8`
- **Typography**: Playfair Display (Headings), Great Vibes (Cursive Script), and Poppins (Clean Modern Body).

### 2. Complete Customer Shopping Experience
- **Dynamic Announcement Bar**: Editable free shipping banner with threshold countdown.
- **Responsive Header**: Desktop navigation, instant search modal, quick wishlist toggle, and animated mobile drawer.
- **Brand Benefits Bar**: 5 core commitments (100% Natural, Cruelty-Free, Premium Quality, Made with Love, Dedicated Support).
- **Category Portals**: Dedicated category hubs for **Cosmetics**, **Skin Care**, and **Hair Care**.
- **About Story Section**: Brand photography, vision, mission, and craftsmanship pillars.
- **Why Choose Pretty Palette**: 4 illustrated feature badges (Handmade, Skin Safe, Cruelty Free, Sulphate Free).
- **Our Best Sellers Carousel**: Live product carousel featuring Matte Lust Lipstick, Radiance Face Cream, Nourishing Hair Oil, and Herbal Kajal with ratings, quick-view, and add-to-bag.
- **Interactive Cart Drawer & Cart Page**: Real-time free shipping progress bar, promo code validation (`WELCOME10`, `GLOW20`, `PRETTY50`), quantity controls, and subtotal calculation.
- **Multi-Step Checkout**: Contact info, shipping address with PIN code validation, and Indian payment gateways (Razorpay, UPI / QR, Net Banking, Cards, and Cash on Delivery).
- **Order Confirmation & Tracking**: Confetti celebrations, live order status progression (Placed ➔ Processing ➔ Dispatched ➔ In Transit ➔ Delivered), and printable/downloadable PDF-ready invoices.
- **Customer Accounts & Wishlist**: Order history, saved address book, profile management, and quick wishlist-to-cart transfer.

### 3. Merchant Admin Panel & Live CMS (`/admin`)
- **Dashboard Metrics**: Live sales revenue, order volumes, inventory levels, and average order values.
- **Product CMS**: Add, edit, delete, set stock levels, update pricing/discounts, and toggle Best Seller badges.
- **Homepage CMS**: Real-time editing of announcement bar text, hero headings, CTA buttons, hero media mode (Image vs Video), why-choose claims, and about story.
- **Order Manager**: Live status management (Placed, Processing, Dispatched, In Transit, Delivered), tracking number assignment, and courier assignment.
- **Promotions & Coupons**: Create discount codes with percentage or fixed deductions and minimum cart thresholds.
- **Store Settings**: Update free shipping thresholds (default ₹999), shipping fee (default ₹99), contact phone, and store address.

## 🛠️ Tech Stack
- **Frontend Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS with custom brand theme extensions
- **Icons**: Lucide React
- **Animations**: CSS keyframes + Canvas Confetti
- **State Management**: React Context with LocalStorage persistence

## 🚀 Getting Started

### 1. Clone the repository:
```bash
git clone https://github.com/muzammil-commits/pretty-pallete.git
cd pretty-pallete
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Run development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production:
```bash
npm run build
```
